## Installation 
1) Initialisation du projet Spring Boot avec Spring Initializr :
   - Spring Web
   - Spring Security
   - Spring Data JPA
   - MySQL Driver
   - OpenAI   

   
2) Configuration du fichier application.properties:
   - Connexion à la base Mysql  


3) Implémentation des classes selon un model MVC :
   - Entity
   - Repository
   - Controller
   - Service
   - Dto
   - Config  


## Démarrage du projet :
  >- mvn spring-boot:run 

## Installation de la base de données
- Installation binaire Mysql sous Windows en tant que service
- se connecter en tant que root
- lancer le script de la creation de la base chatopdb
